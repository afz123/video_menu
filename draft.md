# 📋 Техническое задание и Спецификация: Video Menu Luxury Platform

## 🎯 Концепция и Назначение
Премиальная интерактивная платформа видеоменю для ресторанов высокой кухни, баров и лаунжей. Система разделена на 3 ключевых модуля:
1. **Мобильный QR-клиент для гостей** (`/menu/:slug`) — вертикальная Reels-лента с моментальным автовоспроизведением без звука, ASMR-аудио, мультиязычностью (RU/EN/TJ), фильтрацией и плавающим оформлением заказа.
2. **Уличный Kiosk-дисплей** (`/kiosk/:slug`) — digital-витрина для больших сенсорных экранов/планшетов на улице/входе с рекламным Attract-режимом (видеозаставка), автосбросом по таймеру неактивности (45 сек) и QR-мостом передачи меню на смартфон.
3. **Панель управления ресторатора (CMS / Admin)** (`/admin`) — мгновенный стоп-лист в 1 клик, drag&drop приоритизация, 3-шаговая загрузка видео с авто-транскодированием, редактор премиум-тем.

## 🏗️ Архитектурные требования и Статус реализации

| Модуль / Требование | Описание | Статус |
|---|---|---|
| **Локальное хранение медиа** | Никаких сторонних сервисов (S3, CDN). Видео и постеры хранятся локально в `backend/storage/videos/` и раздаются напрямую через статический маунт FastAPI с кэшированием. | ✅ Реализовано |
| **FFmpeg конвейер** | Автоматическая генерация микро-превью LQIP WebP (320x568 ~10KB) для эффекта размытия при загрузке, четкого постера HD WebP (1080x1920) и оптимизированного мобильного H.264 FastStart лупа. | ✅ Реализовано |
| **Отказоустойчивая БД** | PostgreSQL 16 в Docker (порт 5431) с автоматическим fallback на SQLite (`videomenu.db`), если контейнер временно недоступен. | ✅ Реализовано |
| **Мобильная лента (Reels)** | Свайп-скролл карточек блюд, мгновенный показ LQIP с плавным переходом в видео, ASMR звук по тапу, значки «Стоп-лист» / «Хит». | ✅ Реализовано |
| **Уличный Kiosk Mode** | Полноэкранный Attract Mode с циклическим видео, переход в каталог по первому касанию, таймер бездействия (useInactivityTimer), кнопка «Забрать меню с собой» с QR-кодом. | ✅ Реализовано |
| **CMS Администратора** | Управление категориями и блюдами, тумблер `is_available` (стоп-лист), форма добавления блюда с загрузкой видеоролика, выбор luxury-палитры (Dark Gold, Emerald Royal, Midnight Rose). | ✅ Реализовано |
| **Контейнеризация Docker** | `docker-compose.yml`, `backend/Dockerfile` (с FFmpeg), `frontend/Dockerfile` (Nginx reverse proxy), `.dockerignore`. | ✅ Реализовано |
| **Скрипт запуска run_dev.sh** | Очистка старых портов, определение Wi-Fi IP, проброс портов WSL2, запуск БД в Docker (5431), venv в бэкенде (8088), Vite фронтенда (3033), QR-код в консоли. | ✅ Реализовано |
